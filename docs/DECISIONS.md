## Package version note

`npm audit` on the first install reported high-severity advisories for Nodemailer < 10.0.10 and Zod < 4.6.6 (and critical ones for Vitest's `tinypool` < 2.1.2, dev-only). The project therefore uses **Nodemailer 10, Zod 4, Vitest 4 and React Router 7**, after the changelogs were checked for breaking API changes (Nodemailer 10 only raises the minimum Node version to 20; `createTestAccount`, `createTransport` and `getTestMessageUrl` are unchanged). Other packages use the latest version of the major that the author has verified (Express 5, Mongoose 8, SimpleWebAuthn 13, React 18, Vite 6). Each job's environment metadata records the exact resolved versions.
